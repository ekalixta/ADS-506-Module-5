# Australian Wine Sales Forecasting

ADS 506 Week 5 Shiny app. Uses the course-provided AustralianWines.csv.

Open app.R in RStudio and click Run App. Select varieties, dates, models, training percentage and forecast horizon. Compare validation RMSE to select a model. Future forecasts refit the models on the full selected date range.

Packages: shiny, tidyverse, tsibble, fable, fabletools, feasts, lubridate.

ChatGPT assisted with drafting the code and explanations. The code follows the course's suggested Module 5 workflow.
